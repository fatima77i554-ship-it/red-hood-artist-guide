Впервые вместе проверены здоровье и возрождение,18 NPC, обычный бой Кахо и исходное семейство Frore. Карта, инвентарь, двери, механизмы, настройки и F5/F9 сохранены. Основная версия данных теперь4; миграции из1/2/3 не переписывают файл просто при чтении и сохраняют точные старые байты в backup при следующей записи. Историческая папка user://progress-v1 не переименована.

## Что исправлено при независимой приёмке

- Первый обычный удар —1+event96, затем2/3/2+event96; прежняя цифра2 относилась к другой ветви. Бонус чая теперь действует на melee, лук его не получает.
- NPC449 возвращается449→442; классификатор исправлен с once_hold. Исходный этап Аскорна1=0..2 и условия111/158 входят в единственный progress_store; локальный286 не сериализуется. Условия появления Frore включают исходный98.
- RoomCreate rmPaint01 действительно записывает186=1; native Cath2 после этого исчезает при новом входе. Это подтверждено отдельным raw/native аудитом, флаг не сбрасывался ради теста.
- Разные контракты Кахо и Frore соединены явным адаптером: exact EN365Area256, world/generation/lifetime guards, единый приёмник здоровья. Урон raw9/10/1000 становится10/12/1200 HP на исходном normal-профиле через floor(raw×1.2) ровно один раз. Шипы уважают те же hurt31/iframes110. Старые callbacks не попадают в новый мир.
- Синхронный повторный callback с другим ID больше не создаёт второе списание HP; отказ здоровья не расходует стабильный ID снаряда. Красный и зелёный тесты сохранены. VFX Frore получили исходный порядок над телом.

Старые hardcoded schema2/3 в QA заменены проверкой текущего формата. Ни одна неудачная попытка не записана как успешная.
