# Исправление размещения трамплина rmCastle26

В rmCastle26 (комната 262) исправлен трамплин **105818**. Его эффективный pivot перенесён с **(120, 240)** на **(136, 208)**: на 16 px вправо и 32 px вверх, на верхнюю грань существующего столба 105819. Сила подброса и все исходные тайлы/коллизии сохранены.

Новые игровые ассеты не понадобились. Использован проверенный **MECH_494**: два исходных кадра 16×16, масштаб 1:1, pivot (8,16), точная маска триггера, без боевых хитбоксов. Перед подключением переноса создан и проверен паспорт **PLACEMENT_PAD_105818**, выполнена отрисовка эталонного участка в Godot с наложением маски, pivot и полной опоры шириной 16 px. Проверены свободный триггер и место для исходной маски Кахо на траектории.

## Проверено в Godot 4.6.2

Сценарий управляет реальной героиней в основной игровой сцене; геометрия во время прохождения не подменяется.

1. Подход с исходной опоры (88,224) стоя, без пересечения коллизий.
2. Прыжок на перенесённый трамплин и физический запуск.
3. Подброс без удара в потолок: измеренный подъём после обнаружения запуска **68.25 px**, затем приземление в правом коридоре.
4. Продолжение через исходные уступы до перехода **262→265**.
5. Подход с правой стороны и повторный подброс.
6. Обратный маршрут через левый переход **262→248**.
7. Настоящее событие клавиши **R**: размещение сохраняется; героиня появляется на устойчивой опоре (152,224), без автоматического подброса.

Дополнительно прошли проверки всех 24 движущихся платформ, обе поездки четырёх лифтов, 73 трамплина, базовое перемещение, 252 безопасные точки появления, три узких прохода, 533 корректных целевых входа и сохранение параметров подброса после перехода между комнатами.
