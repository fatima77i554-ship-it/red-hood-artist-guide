Подсказки первого леса

Два authored trigger-объекта. Клавиатура, два профиля Xinput и два Sony. Исходные bitmap-глифы EN/RU и координаты из native Draw.

Выбранный профиль настроек и записанный сценарий bbox игрока. Native RNG для UI не нужен. Полная игровая сцена и прочие акторы остаются вне этого допуска.

Выполненные Draw-команды

Масштаб 320×240. Голубой: glyph rectangles, розовый: pivot панели. Физических опор, solid collision и damage hitbox у UI нет. Alpha меняется в конце Draw.

Исходный trigger и пробный bbox
Жёлтый: authored anchor. Зелёный: collision_rectangle. Голубой: inclusive bbox sPlayerMask132, без рисунка игрока. Проверка precise=false. Пределы trigger ниже комнаты сохранены.
Проверенные значки и метрики
Клавиатурная ветвь строит подпись через buttToString. SPRT192 используется для bbox_right=31. Контроллеры используют исходные кадры 0/1 из SPRT193…196; остальные кадры и Switch-ассеты не подставляются.
